Selected work

Concept studies

Six self-initiated briefs with fictional clients, made to explore identity, poster, packaging and social design.

Pharos Nights

PosterIllustrator

A three-night waterfront festival poster built around the Alexandria lighthouse and a sun that never sets.

Qalam Academy

BrandIllustrator

Identity concept for an online learning platform: a pen nib hidden inside a bold Q, with banner and campaign lines.

Lotus Books

BrandIllustrator

Logo, wordmark and colour system for a neighbourhood bookshop, built from five overlapping petals that read like stacked pages.

Mina Roasters

PackagingIllustrator

Coffee bag and label system for a harbour-town roaster, with a flat kraft bag and one-colour emblem that prints cheaply.

Orbit Learn

SocialPhotoshop

A study-tips campaign set for a fictional learning app: tilted tiles, one big number each and a shared grid.

Nile Type

PosterIllustrator

A type specimen poster for an imaginary typeface: one huge letterform, labelled guides and a tight, readable grid.

All six are concept pieces with invented clients, dates and names.
